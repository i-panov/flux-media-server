# Web release notes — 0.1.35 (фикс карточек и «Продолжить просмотр»)

**Дата:** 2026-11-11. **Версия web:** 0.1.35. **База:** `48aa7fd`.
**Статус:** исправления проверены автотестами; на сервере пользователя
пока развёрнута 0.1.31, для применения нужен rebuild/redeploy.

## Что исправлено

- **Кнопки на карточках.** Mantine `ActionIcon` задаёт `position: relative`
  вне CSS-слоя, из-за чего Tailwind-класс `absolute` у кнопки избранного
  и retry проигрывал: кнопки вставали в поток под карточкой, раздували
  её по высоте и визуально «схлопывались в стопку». Добавлено явное
  правило `.media-card > .absolute { position: absolute; }`.
- **«Продолжить просмотр» на главной.** Лимит был 6, поэтому блок
  выглядел как история просмотров. Теперь показывается только последняя
  незавершённая запись (`limit={1}`), как и на странице «Видео».

## Проверки

- `typecheck`, `lint`, `lint:deadcode`, `build`, `size` — зелёные.
- 230 unit-тестов, 77 Playwright e2e.
- Новые e2e: кнопка избранного имеет `position: absolute` и лежит внутри
  карточки; на главной при двух записях прогресса отображается одна.

## Ограничения

- Изменения не развёрнуты на `flux.ithub24.ru`; текущий live — 0.1.31.
- Реальный ТВ/пульт по-прежнему не проверялся.

# Web release notes — 0.1.34 (ТВ-OSD видео)

**Дата:** 2026-11-11. **Версия web:** 0.1.34. **База:** `ceba883`.
**Статус:** код и автотесты готовы; проверка на реальном Tizen/webOS/VIDA
и с реальным пультом не выполнялась, поэтому релиз не заявляет поддержку
конкретных ТВ.

## Что добавлено

### ТВ-OSD видео

- На `/video/$id` в ТВ-режиме нативные `<video controls>` заменены
  собственным OSD. В обычном режиме поведение не менялось: остаются
  нативные контролы, OSD не рендерится.
- OSD: play/pause, seek −10/+10, таймлайн с текущей позицией, mute и
  громкость, fullscreen и кнопка «К списку видео».
- Панель автоскрывается через ~3 секунды во время воспроизведения;
  на паузе остаётся видимой. Любая клавиша пульта или движение/клик
  мыши показывают её снова. Начальный фокус — на play.
- D-pad: на play ←/→ — seek на 10 секунд, ↑/↓ уводят spatial-фокус к
  другим кнопкам OSD и странице (тупика на play нет). На остальных
  OSD-кнопках стрелки работают как обычная навигация. Громкость
  доступна кнопкой mute и фокусом на слайдер: ←/→ на нём двигают
  значение нативно, ↑/↓ уводят spatial-фокус со слайдера, а не
  запирают его; вертикальный уход не меняет значение слайдера.
  Флаг вертикального ухода сбрасывается на window keyup/pointerdown,
  поэтому pointer seek/volume не блокируются после ухода стрелкой.
  Enter/Space — play/pause, `F` — fullscreen,
  `M` — mute, `MediaPlayPause` и `MediaTrackNext/Previous` (seek).
  Back/Escape по-прежнему уходят в существующий `router.history.back()`.
- Enter/Space на кнопке OSD не дублируют действие: кнопку активирует
  фокус/spatial, глобальный обработчик такие цели пропускает. Глобальный
  seek/volume не перехватывает стрелки, когда фокус на OSD-кнопке или
  слайдере.
- Скрытая панель получает `aria-hidden` и `inert`, слайдеры и кнопки —
  `pointer-events: none`. Клик, который сам был первым pointerdown на
  скрытой панели, только показывает OSD; если панель уже показана
  pointermove, следующий клик сразу работает. После автоскрытия фокус
  возвращается на безопасную OSD-кнопку (play, если фокус был на
  слайдере), а не в слайдер.
- Первый Enter/Space/стрелка на скрытом OSD только показывает панель и
  восстанавливает DOM-фокус; play/pause/mute не срабатывают. Следующие
  клавиши работают обычно. Remote-handler дополнительно учитывает
  spatial `focusKey`, чтобы не дублировать Enter/Space с `clickNode`.
- Доступность: подписи у всех кнопок, `aria-pressed` у mute,
  `role="toolbar"` у транспорта, таймлайн и громкость — слайдеры с
  `aria-valuenow` и подписями.
- Fullscreen: стандартный API и legacy WebKit-ветка
  (`webkitfullscreenchange`); если API нет, кнопка скрыта. Back в
  fullscreen сначала выходит из него и не уводит со страницы.
- Воспроизведение, прогресс, сохранение позиции и восстановление после
  ошибки потока остаются за нативным `<video>`; OSD только читает
  состояние элемента и командует им. `timeupdate` обновляет состояние,
  только пока OSD видим.

## Проверки

- `npm run typecheck`, `npm run lint`, `npm run lint:deadcode`,
  `npm run test` (230 тестов), `npm run build`, `npm run size` — зелёные.
- Unit: маппинг клавиш видео-OSD, media-клавиши, clamp seek/volume,
  отсутствие двойного toggle на кнопке, стандартный/legacy WebKit
  fullscreen.
- Playwright TV: 17 сценариев. Новый `tv-video.spec.ts` проверяет
  фокус на play, Enter play/pause, seek вправо/влево, `MediaPlayPause`
  и Back к списку, уход D-pad с play, громкость через слайдер, выход
  ↑/↓ с volume и timeline без изменения значения, `M`, `F`, Back из
  fullscreen, автоскрытие, клик по скрытому таймлайну без seek,
  первый Enter/↑ после автоскрытия (только показ + фокус, без
  play/mute), второй Enter (play или mute), возврат фокуса на play
  после автоскрытия, pointermove-reveal + клик, pointer seek после
  вертикального ухода со слайдера и скрытие fullscreen-кнопки без API.
  Desktop-проверка подтверждает нативные контролы и отсутствие OSD.
- Полный Playwright e2e: 75 сценариев, 75 зелёных.
- Аудио-фикстура в `player.spec.ts` увеличена до 60 секунд: под
  параллельной нагрузкой 1-секундный трек успевал закончиться и
  переключить очередь, из-за чего тест редактора текста падал не по
  делу.

## Известные ограничения

- Реальный ТВ (Tizen, webOS, VIDA) и пульт не проверялись: автотесты
  используют синтетические клавиши и User-Agent, это не device-smoke.
- В ТВ-OSD нет выбора дорожки субтитров: нативные контролы скрыты,
  дорожки загружаются, но отдельного CC-меню в OSD пока нет.
- Fullscreen: legacy WebKit-ветка покрыта unit-тестом, но на реальных
  приставках запрос может быть отклонён без видимой ошибки; при полном
  отсутствии API кнопка скрыта.
- Overscan и читаемость OSD с 3 метров на реальном экране не проверены.

# Web release notes — 0.1.33 (TV P1/P2, без реального ТВ)

**Дата:** 2026-11-11. **Версия web:** 0.1.33. **База:** `a6d7552`.
**Статус:** код и автотесты готовы; проверка на реальном Tizen/webOS/VIDA
не выполнялась, поэтому релиз не заявляет поддержку конкретных ТВ.

## Что исправлено

### Вход на ТВ

- Поле email, поле кода и кнопки входа — самостоятельные
  `useTVFocusable`-цели (`login-email`, `login-code`, `login-submit`,
  `login-verify`, `login-change-email`).
- Route-focus на `/login` ведёт на email; после отправки письма фокус
  переезжает на поле кода.
- Стрелки вверх/вниз между полем и кнопкой проведены явно: у текстовых
  полей геометрическая навигация spatial-библиотеки не срабатывала.
- Проверено e2e с Tizen User-Agent: автодетект включает ТВ без `?tv=1`,
  клавиатурный ввод и Enter доводят до экрана кода.

### Тумблер ТВ в настройках

- Переключатель темы, тумблер ТВ-режима и Select языка — spatial-цели.
- `destroy()` больше не вызывается при выключении режима: реестр
  focusable-компонентов не обнуляется, навигация после off→on работает.
  Выключение ставит навигацию на паузу, включение — снимает.
- Тумблер выключается Enter и включается Space/Enter; e2e проверяет
  off→on и последующее движение стрелкой.

### Read-only страница артиста

- Read-only определяется capability-слоем, а не одним `tvMode`.
- В ТВ скрыты «Переименовать», «Изменить», «Заменить обложку» даже у
  администратора; треки, «К списку аудио», «Показать ещё» и избранное
  остаются spatial-целями.
- Скелетон страницы — отдельная цель route-focus, чтобы фокус не уходил
  в навбар, пока данные грузятся.

### Сохранение ТВ-режима

- `?tv=1` на заблокированном маршруте (`/upload`, `/trash`, `/admin`)
  сохраняется в `localStorage` до redirect: reload остаётся в ТВ.
- Ручной выбор в настройках больше не перезаписывается эффектом URL.
  Если `?tv=1`/`?tv=0` противоречит выбору, параметр убирается из адреса,
  поэтому reload не включает режим обратно.
- Автоопределение по-прежнему работает без параметра; `?tv=1` остаётся
  принудительным режимом на заход.

### Capabilities и фокус

- `canDownload` в ТВ теперь `false`; скачивание мема и оригинала в админке
  скрыто. Удалён мёртвый `canUseQrLogin`, добавлен используемый
  `canAccessAdmin`.
- `canUpload`, `canEditMetadata`, `canChangeCover`, `canDelete`,
  `canManageTrash`, `canManageCollections` проведены в upload, админку,
  метаданные/обложки, коллекции и корзину.
- Route-focus не сдёргивает фокус из шапки/навбара после того, как
  пользователь сам туда перешёл; автоматический переезд остаётся только
  для скелетона/корня контента и потерянного фокуса.
- Подсказка «включить ТВ» запоминается как закрытая при явном включении.

## Проверки

- `npm run typecheck`, `npm run lint`, `npm run lint:deadcode`,
  `npm run test`, `npm run build`, `npm run size` — см. журнал коммита.
- Playwright TV: 10 сценариев (`tv.spec.ts`, `tv-login.spec.ts`,
  `tv-artist.spec.ts`), включая Tizen-логин, off→on, `/upload?tv=1` +
  reload, read-only артиста и возврат фокуса из overlay.
- Полный Playwright e2e: 68 сценариев, все зелёные.

## Известные ограничения

- Реальный ТВ (Tizen, webOS, VIDA) и пульт не проверялись. Автотесты
  используют синтетические клавиши и User-Agent, это не device-smoke.
- Видеоплеер использует нативные `<video controls>`; отдельный ТВ-OSD
  (play/pause, seek ±10, fullscreen с пульта) остаётся открытым P1.
- QR/device-code вход не реализован — это следующая фаза roadmap.
- VidaaOS/Hisense и старые WebKit-приставки не проверялись.

- В мини-плеере появился компактный слайдер громкости (desktop).
- В полном плеере громкость убрана из отдельной строки и стоит в одном
  ряду с shuffle/prev/play/next/repeat; больше не растянута на ширину
  прогресса.
