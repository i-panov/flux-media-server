# Документация Flux Media Server

Актуальная документация живёт в трёх местах: корневой `README.md` (быстрый
старт), `AGENTS.md` (правила разработки и архитектура) и этот каталог
(исторические отчёты и решения).

| Документ | Статус | О чём |
|---|---|---|
| [../README.md](../README.md) | актуальный | запуск, Docker, клиенты, проверки |
| [../AGENTS.md](../AGENTS.md) | актуальный | структура, команды, конвенции, версии |
| [review-2026-11-09.md](review-2026-11-09.md) | итоговый отчёт | ревью, закрытые находки, осознанные ограничения, журнал коммитов |
| [mobile-parity-plan-2026-11-09.md](mobile-parity-plan-2026-11-09.md) | план | дорожная карта mobile до паритета с Flutter: фазы, файлы, тесты, риски |
| [mobile-parity-handoff-2026-11-10.md](mobile-parity-handoff-2026-11-10.md) | handoff | текущее состояние, Tasks 8–25, P3-долги и правила передачи другому агенту |
| `superpowers/` | локальный архив | старые планы и спеки, **не коммитятся** (`.gitignore`) |

## Правила

- `docs/superpowers/` — исторический архив, не источник истины. Если план
  нужен в репозитории, переносите его в `docs/` и обновляйте под текущий код.
- Новые архитектурные решения фиксируются в `AGENTS.md` или отдельным
  документом в `docs/`; отчёт о ревью не переписывает историю задним числом.
- Ссылки на код — относительные, на коммиты — короткий хеш.
- Legacy `frontend/` (Flutter) не развивается и описан только как справка.
