## Правила

- `docs/superpowers/` — исторический архив, не источник истины. Если план
  нужен в репозитории, переносите его в `docs/` и обновляйте под текущий код.
- Новые архитектурные решения фиксируются в `AGENTS.md` или отдельным
  документом в `docs/`; отчёт о ревью не переписывает историю задним числом.
- Ссылки на код — относительные, на коммиты — короткий хеш.
- Legacy `frontend/` (Flutter) не развивается и описан только как справка.
