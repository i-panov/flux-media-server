# core — общее ядро веба и будущего мобильного приложения

Чистый TypeScript: модели (zod-схемы + типы), API-функции, опции
TanStack Query, форматирование. При старте `mobile/` папка целиком
переезжает в `packages/core` и подключается как workspace-пакет —
импорты внутри папки относительные, внешних веб-зависимостей нет.

## Границы

Разрешено: `fetch` (через инжектируемый `CoreFetcher`), `zod`,
`@tanstack/react-query`, чистый TS.

Запрещено: DOM, роутер, Mantine, React, React Native, `localStorage`,
куки, платформенные URL. Транспорт (`CoreFetcher`) подставляет
приложение: веб — `apiFetch` (same-origin + cookies), мобильное —
абсолютный URL + Bearer.

## Что внутри

- `media.ts` — схемы `Media`/`Subtitle`/списков, fetch-функции и
  фабрики опций запросов. Хуков (`useQuery`) здесь нет: их тонкие
  обёртки живут в платформенном слое (`api/media.ts` в вебе).
- `format.ts` — чистые форматтеры (длительность).
