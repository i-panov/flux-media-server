# core — совместимость с @flux/shared

Модели, zod-схемы, fetch-функции и форматтеры переехали в
`packages/shared/src/core` и публикуются через `@flux/shared`.
Файлы здесь — тонкие реэкспорты для старых импортов веба; новый код
может импортировать напрямую из `@flux/shared`.

Новый общий код кладите в `packages/shared/src/core`, а не сюда.
